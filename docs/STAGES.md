# План разработки проекта go-proxy-guard

## Этап 1: Базовая структура проекта
**Цель**: Создание структуры директорий согласно golang-standards/project-layout и инициализация проекта

**Задачи**:
- Создать структуру директорий (cmd/, internal/, pkg/, configs/, scripts/, docs/, test/, deployments/, api/)
- Инициализировать go.mod
- Создать базовые файлы: README.md, Makefile
- Создать примеры конфигурационных файлов (configs/app.json, configs/proxy.json)

**Результат**: Готовая структура проекта с базовыми файлами

---

## Этап 2: Модуль конфигурации
**Цель**: Реализация загрузки и парсинга конфигурационных файлов

**Задачи**:
- Создать `internal/config/` с типами для app.json и proxy.json
- Реализовать загрузку и валидацию конфигурации
- Поддержка парсинга JSON с валидацией обязательных полей
- Обработка ошибок конфигурации

**Результат**: Работающий модуль загрузки конфигурации

---

## Этап 3: Модуль логирования
**Цель**: Реализация системы логирования с ротацией

**Задачи**:
- Создать `internal/logger/` модуль
- Реализовать поддержку форматов JSON и text
- Реализовать ротацию логов по размеру и времени
- Поддержка уровней логирования (debug, info, warn, error)
- Безопасное логирование (маскирование токенов, не логирование ключей)

**Результат**: Полнофункциональная система логирования

---

## Этап 4: Модуль управления ключами
**Цель**: Реализация генерации, шифрования и хранения криптографических ключей

**Задачи**:
- Создать `internal/keys/` модуль
- Реализовать генерацию ключей для всех алгоритмов (HS256, RS256, RS512, ES256, EdDSA)
- Реализовать шифрование ключей с использованием AES-256-GCM
- Реализовать работу с мастер-ключом (из env или файла)
- Реализовать сохранение/загрузку ключей из файловой системы
- Реализовать резервное копирование ключей
- Управление правами доступа к файлам (0600)

**Результат**: Модуль управления криптографическими ключами

---

## Этап 5: Модуль Redis
**Цель**: Реализация работы с Redis для хранения использованных refresh токенов

**Задачи**:
- Создать `internal/redis/` модуль
- Реализовать подключение к Redis с поддержкой пула соединений
- Реализовать сохранение использованных refresh токенов с TTL
- Реализовать проверку использования токенов
- Обработка ошибок подключения и таймаутов

**Результат**: Модуль работы с Redis

---

## Этап 6: JWT утилиты
**Цель**: Реализация работы с JWT токенами

**Задачи**:
- Создать `pkg/jwt/` модуль
- Реализовать генерацию JWT токенов с поддержкой всех алгоритмов
- Реализовать валидацию JWT токенов (проверка формата, подписи, времени жизни)
- Реализовать извлечение и парсинг claims
- Поддержка стандартных claims (type, jti, exp, iat)

**Результат**: Утилиты для работы с JWT

---

## Этап 7: Модуль аутентификации
**Цель**: Реализация эндпоинтов генерации и обновления токенов

**Задачи**:
- Создать `internal/auth/` модуль
- Реализовать эндпоинт `/api/v1/tokens/generate`:
  - Проверка IP whitelist
  - Валидация запроса
  - Генерация пары токенов (access + refresh)
  - Возврат токенов
- Реализовать эндпоинт `/api/v1/tokens/refresh`:
  - Проверка IP whitelist
  - Валидация refresh_token
  - Проверка использования токена в Redis
  - Генерация новой пары токенов
  - Помечение старого refresh_token как использованного
- Интеграция с модулями keys, redis, jwt

**Результат**: Работающие эндпоинты генерации и обновления токенов

---

## Этап 8: Модуль проксирования
**Цель**: Реализация HTTP reverse proxy с маршрутизацией

**Задачи**:
- Создать `internal/proxy/` модуль
- Реализовать валидацию Host header
- Реализовать маршрутизацию по доменам
- Реализовать glob matching для путей
- Реализовать проверку HTTP методов
- Реализовать проверку IP whitelist/blacklist
- Реализовать переписывание путей (rewrite_path)
- Реализовать HTTP reverse proxy с поддержкой всех методов
- Реализовать добавление заголовков (X-JWT-* из claims)
- Обработка таймаутов и ошибок

**Результат**: Полнофункциональный HTTP reverse proxy

---

## Этап 9: HTTP сервер и интеграция
**Цель**: Объединение всех компонентов в единое приложение

**Задачи**:
- Создать `cmd/proxy-guard/main.go`
- Реализовать инициализацию всех модулей
- Реализовать HTTP сервер с маршрутизацией:
  - `/api/v1/tokens/generate` → auth модуль
  - `/api/v1/tokens/refresh` → auth модуль
  - `/*` → proxy модуль (с валидацией JWT)
- Реализовать middleware для:
  - Логирования запросов
  - Извлечения IP адреса (X-Forwarded-For)
  - Валидации JWT токенов для proxy запросов
- Реализовать graceful shutdown
- Обработка сигналов (SIGTERM, SIGINT)

**Результат**: Полностью работающее приложение

---

## Этап 10: Docker и deployment
**Цель**: Подготовка к развертыванию

**Задачи**:
- Создать Dockerfile
- Создать docker-compose.yml с Redis
- Создать скрипты сборки (scripts/build.sh)
- Создать скрипты деплоя (scripts/deploy.sh)
- Настроить volume mounts для ключей и логов
- Обновить README.md с инструкциями по запуску

**Результат**: Готовое к развертыванию приложение

---
